# 堆对象与字段身份开发验收

revision18 在语言无关 IR 新增 AllocateObject，区分普通堆对象身份与具有 open/closed 协议的资源。Python 普通类构造已发出此操作，隐式 self 在调用中获得对象身份。

求解器的位置解析逐层读取 (ObjectId, field) 堆槽，变量保存对象引用集合；a/b 为别名时共享字段，重新绑定字段不会改写先前取出的引用。字段读取缺失或接收者不确定均保留未知。

字段强更新只允许确定单个非摘要对象。多目标或循环分配摘要使用弱更新；分支一侧缺字段时不能把另一侧赋值当成全部路径初始化。跨函数调用共享并带回堆图，正常和异常后继均传播字段变化，同时保留调用方局部绑定。

Unknown 按已声明影响范围追踪字段可达对象（含循环），污染可达资源状态和字段指向；未知字段指向扩大污染范围。无法解析的字段写入使既有堆图保守失去证明。普通对象不能被当作打开文件进行协议操作。

13项堆图回归覆盖实例别名/独立对象、字段重绑定、嵌套字段、跨调用返回别名、正常/异常写回、循环可达Unknown、不确定写接收者、分支缺字段、多目标弱更新、循环摘要、普通对象非资源协议及不相交对象。旧未初始化投影反例保留，仍不能verified。

Python 字段读取/写入仍未接入：需先证明属性访问为直接数据字段，排除描述符、__getattribute__/__setattr__、继承与动态修改，再提交稳定字段类型事实。不能因为求解器有Heap，就宣称任意Python类已被覆盖。固定真实语料里程碑继续保持开放。

安装验证：305项Rust测试、fmt、clippy、release通过；构造器端到端错误/修复/未知仍1/0/3，compare仍resolved/became_unverified。固定Museon语料仍5/11；3源片段/11变体哈希核对通过，未执行目标代码。
