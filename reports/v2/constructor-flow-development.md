# 普通构造器效果开发验收

v2-resource-cfg-17 已安装。普通无状态类 __init__ 接入项目 Invoke：隐式 self、位置参数类型推导、跨模块/自调用效果与独立异常后继均复用现有 IR 和求解器。默认分配与初始化分开；__init__ 的 None 返回不覆盖实例表达式。

examples/v2/constructor-flow 保留跨模块 Worker.__init__ → self.finish → f.close 调用链。通过安装 CLI 验收：构造后读别名退出1；先读后构造退出0，比较resolved；未知构造器退出3，比较became_unverified。不能依据构造器名字猜测转移或关闭。

八项构造器回归覆盖关闭/修复、实例结果及别名、分支possible、关闭后raise经Exception处理器传播、合法None与非法非None返回、字段写入及未知调用、参数不匹配、跨模块调用。原来拒绝所有自定义初始化器的反例改为 __new__ 分配hook；继承、描述符与其他dunder仍未知。ValueError精确匹配仍未覆盖，不能用Exception家族测试宣称精确子类匹配。

292 Rust 测试、fmt、clippy和release通过。固定语料仍5/11，3个源片段与11个变体哈希未变，没有执行目标Python或修改Museon。此为构造器效果子集交付，不是字段/真实调用链里程碑完成，不构成独立AI收益证据。

字段写入、字段对象身份、带默认值或关键字/variadic绑定、继承/自定义分配、非None初始化返回仍不支持。初始化未知会沿调用连通分量污染精确派发。当前实例类型仅支持无状态派发；资源别名仍由求解器跟踪。
