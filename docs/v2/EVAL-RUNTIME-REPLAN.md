# 修复实验运行限制与接续修正

2026-09-13：正式 AI 修复尝试仍为 0。此前几轮在模型 host 限制未解决时继续增加准备材料，但执行 Todo 一直显示 runnable，导致反复选择同一条实验主线。责任层是 agent 的状态书写与交付选择，不是已经证明的 LoopX 调度 bug。

- 将模型对照 Todo 保留为 blocked，写清恢复条件：经过验证的无开发历史、无法读取答案目录的模型运行接口，以及双方一致的模型/预算设置。不是等待用户授权，不创建笼统 user gate。

- 保留全部实验目标、三份 smoke 输入与初始工具反馈；独立评审和 72 次先导未完成，不标 done。
- 自动接续返回已有分析器主线：类型/类方法资源调用链。仅使用开发场景，禁止读取或使用 pilot 草稿来调规则，直到先导冻结及执行完毕。
- 后续只有新 host 能力证据才重新开启模型运行；不得每轮重复报告同一阻塞。正常的分析器实现进度与未运行实验分开记录。
